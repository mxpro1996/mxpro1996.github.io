敝帚自珍或许会成为当代的底色。往前推到去年十二月，我一度以为自己挺不过来了，此后连锁反应，逐渐演变成了虚无主义。常说，人活着总归得有个盼头，于是也就有了「势不可去尽」的理念：做人做事处处留一线，到了绝境，或许还能抓住些许救命稻草。到了今年五月，意义主义又开始泛滥，整体精神头只能说是「十分美丽」。

就像跑在笼子里的仓鼠，又像推着巨石上山的西西弗斯，我早已忘记纯粹享受生活究竟是一种怎样的人生态度，似乎总要以某个目标为准线，才能心甘情愿地为之不懈努力。于我而言，存在主义危机往往发生在目标完成之后，因为事情一旦有了结果，归因机制便会开始运转，重新审视得失与投入产出比。反倒是在事情尚无定论、足够冷门，乃至无人问津的时候，我总能使出浑身解数，「升天入地求之遍」。

那些没人愿意坐的冷板凳，冷门到无人问津的机型与工具，以及一些近乎失传的古早事物，对我而言早已不只是猎奇，而是一种朴素与愚昧并存的所谓「英雄主义」，总想着舍我其谁，于是便埋头苦干起来。可复盘之后才发现，这些事情对自己似乎没有任何实际获利。拓荒阶段，往往人人都几番推脱，表示爱莫能助；等到后来出了成果，却又纷纷回来摘桃，想着分上一杯羹。以前脱产时间比较长的时候，我经常做这种大公无私的「慈善」，当时甚至没想过自己是不是在被拉去打白工、被人白嫖，只是一味地用「帮别人也能提升自己的技术」来说服自己。后来四处谋生，迫于生计，才逐渐想通：在对方眼里，我或许就是一个被理想主义驱动的大冤种。

上一轮虚无主义发生在今年五月。当时，我把通过归档求来的那些东西陆续公开了。回头看整个历程，其中相当一部分都是自己低声下气、四处交涉才求来的。之所以选择放出来，主要也是担心这些东西最终砸在自己手里，毕竟我个人一直处于朝不保夕的状态。其实总的看来，我已经厌倦了充当这个中介人。你辛辛苦苦做出来的 study case，基本上一经汇总发布，就可能被 agent 洗稿，再变成 INFOQ、掘金，抑或某个个人博客上的一篇文章。既然如此，干脆就把那些细写的文章都撤了。自己一些可能具有 profit 的分支和提交，也采取了同样的处理方式：delist，留作自娱自乐和纯粹的研究用途。

这其中存在一个很典型的死循环：「不放，怕砸在自己手里；放了，又发现其实对自己无益。」发布之前不假思索，发布之后又开始后悔，这种事情已经发生过很多次。说到底，man-made 的价值目前似乎正在被架空。就像我当初折腾 25262 那几个 CVE 一样，那时我还挺希望借助 AGENT，比如 Claude 和 GPT，能够畅通无阻地推进整个过程，结果即便是 deliberate 的研究行为，也依然可能被判定为 cyber abuse，后来索性自己分析了。对于眼下这种污名化的处境，以及石器时代的手工劳作和钻木取火、打火机之争，我其实颇有感慨。

为了应对亲手完成一系列任务之后，反而被自己挤压出来的存在主义危机，我做了上面这些调整，也给自己设定了一些自认为永远找不到的 LostMedia，作为新的任务目标。结果到了八月底，这些东西竟然被我一股脑儿全铲平了。无论是 CDN 反查、安卓包名池命中，还是翻旧 SD 卡、恢复老账号，莫名其妙地全线大捷。可这一次，胜利并没有带来多少成就感，反而让我觉得更加悲凉。因为其中有很多事情，我几乎是不过脑子就直接提交了出去，全然不顾自己此前在这些事情上花费过多少心思、做过多少交涉。更有甚者，甚至能够以一种近似计算工时的频率催促我帮忙。直到这时候，我才意识到，自己该退场了。

在整个探寻和申请的历程中，我大多是以一种作壁上观的心态推进事情的，却没想到自己竟然有幸从挑战「永远不可能」，一路走进了壁画之中。全线大捷固然是真实的，但也正是这份大捷，让我从九月份开始进入了新一轮的存在主义危机。AIGC/AGENT 的产出，以及如今这种近乎许愿式的风潮，也让我逐渐正视自己长期以来「老好人」性格中的缺陷。我开始意识到，向过去是求不到答案的。无论为那些古早的旧物裱上多么精致的琥珀，它们终究只是被定格的消逝。作为一个 seeker，我很不幸地总要亲自尝到岁月的流毒，以至于后劲很大。

总之，对于目前这种成果导向的环境，我已经感到相当迷茫，因此最近极少再主动提供自己的 flow。既然大家只需要向 AGENT 许愿就好，那么比起重新入局，我或许更愿意暂时退到场外，观望一阵，坐享其成，至少这样也不至于再让自己吃亏。至于个人提升，还是更倾向于沉下心来，继续做点真正属于自己的事情。正如卡里古拉写下的最后一句：「I'm still alive」（我还活着）。
